# AnhXtanh School Life V17

## V17 changes
- Removes the old meme posters from the school environment.
- Keeps the existing V16 school map, multiplayer, NPCs, classrooms, canteen, library, events, emotes and schedules.
- Updates the visible game version to V17.
- Adds a subtle idle breathing animation while the player is standing.
- Keeps the white AnhXtanh uniform and school logo.

## Run locally
1. Install Node.js (LTS).
2. Extract this folder.
3. Open a terminal in the folder and run `npm install`.
4. Run `npm start`.
5. Open `http://localhost:3000`.

## Deploy
Use the included `render.yaml` on Render. The project uses Node.js and WebSocket multiplayer.
