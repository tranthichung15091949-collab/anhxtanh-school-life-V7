# AnhXtanh School Life V15 — Small Peak Event 🎆🤖

## Tính năng V15

- **Chế độ chụp ảnh:** Ẩn/hiện giao diện để chụp hình trong game; bỏ khối màu tím che khuất khu vực sân khấu.
- **Cổng trường:** Hiển thị dòng chữ **✨ LỚP 10C10 ✨** phía trên cổng.
- **Pháo hoa nhỏ:** Từ ngày **10/11/2026 đến 20/11/2026**, xuất hiện mỗi tối **22:00–22:59** theo giờ Việt Nam (UTC+7).
- **Đại pháo hoa:** Diễn ra từ **23:59:00 đến 23:59:59 ngày 20/11/2026**, kết thúc lúc **00:00 ngày 21/11/2026**.
- **Small Peak Event:** Ba linh vật robot hoạt hình tự thiết kế, lấy cảm hứng từ phong cách animatronic, xuất hiện trong sân trường.
- **Âm nhạc bí mật:** Chỉ hiển thị **🎵 UPCOMING SOON**; không nhúng bài hát chưa được cấp phép.

## Cập nhật lên GitHub / Render

1. Sao lưu phiên bản hiện tại.
2. Trong kho GitHub, mở thư mục `public/`.
3. Thay `public/game.js` và `public/index.html` bằng file V15 tương ứng.
4. Tải file `README_V15.md` này lên **thư mục gốc** của kho (cùng cấp với `package.json`).
5. Nhấn **Commit changes**. Nếu Render đang bật Auto Deploy, chờ triển khai hoàn tất rồi tải lại trang.
